## ✨ 特徴

- マルチモデル切り替えに対応
- テーブル、コードブロック、区切り線、引用ブロックのスタイライズされたレンダリングと、比較的完全な LaTeX 数式のレンダリング（*化学式などの追加拡張を含む*）
- 過程表示付きの思考モード、出典を確認できるウェブ検索、会話へのファイル添付に対応
- 充実した会話履歴管理
- 複数のテーマカラー（Material You ダイナミックカラーとカスタムカラーを含む）とシステムのダークモード追従、チャット画面の背景画像の変更
- カスタムシステムプロンプトとモデルパラメータの調整
- スマートフォンとタブレットのアダプティブレイアウト
- 滑らかなアニメーションと、個人色のある Material You スタイル
- About ページに摘まめるアイコンがある（

## 🚀 クイックスタート

### インストール

#### 方法一：GitHub Releases からダウンロード（推奨）

1. 本プロジェクトの [Releases](https://github.com/MRoldL001/MChat/releases) にアクセス
2. 最新の `.apk` ファイルをダウンロード
3. スマートフォンにインストール（提供元不明のアプリの許可が必要になる場合があります）

#### 方法二：ソースからビルド

> [!WARNING]
>
> 一般のユーザーにソースからのビルドは推奨されません。手間がかかる上に、`.apk` をビルドする際：
>
> `debug` パッケージをビルドした場合、インストールパッケージの容量が大きくなり、デバッグタグが付いているためシステムインストーラーでインストールできません
>
> `releases` パッケージをビルドした場合、安全性のため開発者が保有する署名鍵は公開されません。自己署名の場合、更新のたびに同じ鍵で再ビルドする必要があり、開発者が配布する `.apk` への直接更新はできません

1. `git clone` で Repo をローカルにクローン
2. `Android Studio`、または Android 開発プラグインを入れた任意の `JetBrains IDE` でプロジェクトを開く
3. `Gradle` を同期
4. 実行、または `.apk` をビルド。自己署名での `releases` ビルドを推奨

### 設定

1. アプリの初回起動時、右上の設定アイコンをタップ
2. 小米 MiMo API キーを設定
3. （任意）API Base URL を設定
4. （任意）カスタムシステムプロンプトを設定し、モデルパラメータを調整
5. チャットを始めましょう！

## 📱 対応要件

- Android 8 (API 26) 以上
- ダイナミックカラーのテーマは Android 12 (API 31) 以上のみ対応
- 予測的戻り操作は Android 14 (API 34) 以上のみ対応
- ライブ通知は Android 16 (API 36) 以上のみ対応

## 📖 使い方

### メッセージの送信

下部の入力欄に内容を入力し、送信ボタンをタップしてメッセージを送信

### モデルの切り替え

上部の現在のモデル名をタップし、モデル選択画面で別のモデルを選択

### 思考過程の閲覧

AI が思考モードを有効にしている場合、「思考過程」カードをタップして展開し、AI の推論過程を確認できます

### 検索結果の閲覧

AI がウェブ検索を有効にしている場合、「検索結果」カードをタップして展開し、AI の情報源を確認できます

### ファイルの添付

入力欄左側のボタンをタップすると、その会話にファイルを添付できます（一部のモデルは非対応の場合があります）

### コードブロック

コードブロックは特定言語のアイコンとコードのシンタックスハイライトに対応

- 全画面表示：コードブロック右上の全画面ボタンをタップすると全画面に展開

- コードのコピー：コードブロック右上のコピーボタンをタップするとコードをコピー

### 会話の管理

- 新しい会話：サイドバーの新規ボタンをタップ
- 会話の選択：サイドバーの履歴から会話をタップ
- 会話の削除：会話リストの削除アイコンをタップし、長押しで削除を確認
- 再生成：最新のメッセージ下部の円形ボタンをタップして再生成
- 編集して再生成：最新のメッセージ下部のペン型ボタンをタップし、入力欄で内容を修正して再度送信をタップすると再生成
- 編集の取り消し：最新のメッセージ下部のペン型ボタンをタップした後、会話内容を復元したい場合は、入力欄左側の矢印型ボタンをタップして編集を取り消せます

## 🔧 高度な機能

### ウェブ検索

有効にすると、AI がリアルタイム情報をウェブ検索し、情報源を示します

### 思考モード

有効にすると、AI が思考・推論過程を表示します

### スキルモード

- **詩人モード**：入力内容を古体詩に変換
- **学習モード**：段階的な教授法で新しい知識の学習をサポート

### ファイルのアップロード

入力欄左側のプラスボタンをタップして写真の撮影またはファイルのアップロード。画像・音声・動画、および**混合アップロード**に対応

### カスタムプロンプト

設定でカスタムシステムプロンプトを追加し、AI の行動とスタイルをカスタマイズ

### パラメータ設定

設定でモデルの各種パラメータを変更し、体験をパーソナライズ
